# PRESET 03 — apple_premium
**Signature** : UI motion haut de gamme inspiré des interfaces Apple, **sans affiliation ni logo officiel**, reconstruit pour Edit+.

## Intention
Design produit premium et presque invisible : précision optique, simplicité, hiérarchie, silence, fluidité. La vidéo ne doit jamais faire « template Canva ».

## Montage
- Facecam prioritaire, cuts naturels, musique facultative.
- Bulles de type iMessage : géométrie cohérente, angles doux, rayons optiques, ombres fines, bleus sophistiqués / gris neutres / surfaces translucides mesurées, textes suffisamment grands sur mobile.
- Bulles **uniquement** si l'histoire le justifie. Si c'est une métaphore visuelle, aucune fausse identité d'expéditeur ou prétendue conversation réelle.
- Densité basse ; une interaction à la fois. Très peu de grandes cartes. Éviter les énormes panneaux qui recouvrent la personne.
- Titres courts, espacements exigeants, interpolations élégantes ; entrée/sortie subtiles, sans ressort excessif.
- Animation de chiffre uniquement si chiffre présent dans les paroles ou une source vérifiée.
- Son : micro-interactions discrètes uniquement lors d'actions visuelles significatives, jamais de copie des sons système officiels.

## Anti-patterns
Turquoise saturé arbitraire, cartes massives, bulles plastiques, police trop petite, fausse messagerie, transitions bruyantes, effets visibles parce que l'outil les propose.

## Acceptation
Les bulles paraissent issues d'une vraie direction produit, avec gestes et voix préservés ; leur présence est narrativement justifiée. V4/V5/V6 restent des **essais**, non un étalon de validation.
