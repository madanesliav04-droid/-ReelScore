# Social+ local sur Windows

Le guide actuel, avec installation simplifiée, HTTPS local et accès Safari iPhone, est **[WINDOWS_IPHONE.md](WINDOWS_IPHONE.md)**.

Il remplace les anciennes instructions limitées à `localhost`. Il conserve les moteurs existants, SQLite, les vidéos privées et l’authentification avec MFA du propriétaire. Aucun tunnel, hébergement public ni service payant n’est utilisé.
